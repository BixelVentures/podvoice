# Test/lint toolchain. Install ON TOP of requirements.txt, into a Python 3.12 venv:
#
#   python3.12 -m venv .venv
#   .venv/bin/pip install -r podvoice/requirements.txt -r podvoice/requirements-dev.txt
#

# lacks asyncio.timeout (3.11+) and had no aioesphomeapi, so 7 tests "failed" for
# environment reasons alone and every "suite green" claim from that machine was partly
# meaningless. pyproject already declares requires-python = ">=3.12"; this file is the
# reminder that the venv has to match it.
